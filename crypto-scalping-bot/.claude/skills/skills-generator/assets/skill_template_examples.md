# Skill Template Examples

This document contains example skill templates demonstrating different patterns.

## Simple Task-Based Skill Template

```markdown
---
name: example-task-skill
description: Performs specific tasks X, Y, and Z. Use when user requests operations related to X, Y, or Z.
---

# Example Task Skill

## Overview

Brief explanation of what this skill enables.

## Quick Start

1. Step one
2. Step two
3. Step three

## Task: Doing X

Instructions for task X.

## Task: Doing Y

Instructions for task Y.
```

## Workflow-Based Skill Template

```markdown
---
name: example-workflow-skill
description: Guides through multi-step workflow for accomplishing goal. Use when user needs to complete process A.
---

# Example Workflow Skill

## Overview

This skill guides through a structured workflow.

## Workflow Decision Tree

1. Determine task type
2. Choose appropriate approach
3. Execute steps
4. Validate results

## Step 1: Initial Setup

Detailed instructions for step 1.

## Step 2: Main Processing

Detailed instructions for step 2.

## Step 3: Finalization

Detailed instructions for step 3.
```
